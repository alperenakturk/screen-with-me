# Name ideas (round 1, Oct 2026)

> Inspiration for the final product name (ROADMAP §4, "Final product name"). **Nothing is decided and nothing in the
> code is renamed**: the decision belongs to the owner. Earlier trademark research: `name-research.md`.
> Visual version of this file (Turkish, with wordmark mocks): the "Yeni Ad Fikirleri" artifact (https://claude.ai/artifact/PQ5MoBZgkxQrqtasNmtn3q, private to the owner).

**Method and limits:** web search only (28 Oct 2026). Domain lookups (RDAP/whois) were blocked by the session's
network, so **no domain was checked**. "Clean" means "no same-name product found by search engines", not "free to
register". Before deciding, run the checks in `name-research.md` §2 (TÜRKPATENT, TMview, USPTO, WIPO, Chrome Web
Store, domains) for the 2–3 finalists.

**Briefing used:** free, account-free, any video on any site, friends far apart, warm tone ("Ayrı ekranlar, aynı an.",
"Sana bir koltuk ayırdım 🍿"). Avoid crowded words (sync, couch, watch, party, tele-). Short (4–8 letters), works in
TR and EN, good mascot/logo, good `.app` / `.com` and social handle.

**One general finding:** avoid popcorn names. "Popcorn Time" is a famous piracy app, and the Chrome Web Store policy
already makes us careful about anything that sounds like piracy. Popcorn is fine as a mascot prop, not as the name.

## Top 5

| # | Name | Why |
|---|---|---|
| 1 | **Anbean** | Says our slogan in one word ("aynı an" → an be an), real Turkish meaning but looks invented to the world, six letters, no product found with the name. Strong as a trademark because it does not describe the service in English. |
| 2 | **Yanyana** | The clearest picture of what we do (side by side), musical repeat, very easy logo (two dots side by side), clean search. Pronounceable everywhere. |
| 3 | **Sofaloop** | The best English-first option: invented, friendly, still clean after a second search. Good if the global audience matters more than the Turkish story. |
| 4 | **Balkon** | Readable in many languages, a real cinema seat (the balcony) and a Turkish everyday image. Great mascot and scene art. Weakness: a common word, so domains and handles need a suffix (balkon.watch, getbalkon). |
| 5 | **Seyirdaş** | The most original Turkish coinage and a lovely meaning (watching buddy). Best if Turkey is the first market; the "ş" costs us on domains and abroad. |

## All candidates by direction

Status key: `clean` = Clean: no same-name product found · `caution` = Caution: same name used elsewhere · `taken` = Taken in or near our category · `risky` = Risky meaning or confusion · `unchecked` = Not checked yet.
