## 2. Is there a registered trademark? (how to check yourself)
Search each database for **"screenwithme"**, **"screen with me"**, **"screen with"**, **"withme"** and note results in
classes **9, 38, 41, 42**.

**Relevant Nice classes:**
- **9:** downloadable software, browser extension, mobile app → **required**
- **42:** non-downloadable online software (SaaS), software services over a website → **required**
- **38:** online chat rooms, voice/video communication, data transmission → good to have (we have chat + voice)
- **41:** entertainment, online game services (in-room games) → optional

1. **TÜRKPATENT (Turkey):** turkpatent.gov.tr → "Araştırma" → **Marka Araştırma** (free) or EPATS via e-Devlet; search
   "contains"; check status (registered / application / published (opposition open) / refused / invalid). Similar
   (not identical) marks are not fully shown; most attorney firms do a free preliminary search.
2. **TMview (EU + Turkey and many offices):** tmdn.org/tmview; filter Nice class 9, 38, 41, 42; status Registered and
   Filed.
3. **USPTO (US):** tmsearch.uspto.gov → wordmark search; only "Live" records matter.
4. **WIPO Global Brand Database:** branddb.wipo.int (includes Madrid international registrations).
5. **Domains and stores:** Cloudflare Registrar (our server is already on Cloudflare; at-cost prices) or who.is for
   `.app`, `.com`, `.ai`. Search the name in the Chrome Web Store, App Store, Google Play, Product Hunt, GitHub.

Send Claude the results (screenshots are enough): owner, country, class and status of every record.

## 3. Risk assessment

**How trademark law works (simplified):**
- Rights are per **country and class**. An EU mark doesn't block you in Turkey; a health campaign doesn't block a
  software class.
- Infringement usually needs **the same or a similar sign** + **the same or similar goods/services**, creating a
  likelihood of confusion. Very famous marks are protected in every class.
- Turkish law: Industrial Property Law No. 6769 (SMK). Applications are published in the Official Trademark Bulletin;
  anyone may oppose within **2 months** (SMK art. 18). TÜRKPATENT checks similarity ("relative grounds") only **when
  someone opposes**.
- **Unregistered** use gives a little protection (SMK art. 6/3) if the sign has become known — a weak shield for a
  small project. Bad-faith registrations can be cancelled.

| Scenario | What happens | Risk |
|---|---|---|
| The AI product is unregistered and in a different business | Both can use it; whoever registers first is stronger | **Low** (most likely given current findings) |
| It is registered in 9/42 and screen/watch-related | Cease-and-desist, store takedown complaint, forced rename | **High** ⚖️ |
| Registered but in a very different class (health, ads) | Usually no problem | **Low** |
| Someone else registers "ScreenWithMe" in 9/42 before us | The name could be taken; fighting via art. 6/3 or bad faith is hard and costly | **Medium** (risk of not registering) |
| Confusion with the "Watch With Me" extension | Different words ("screen" / "watch") but same category; no sign they are registered | **Low** |

**Chrome Web Store:** infringing others' IP (including trademarks) or impersonation is prohibited
([policy](https://developer.chrome.com/docs/webstore/program-policies/impersonation-and-intellectual-property)). In
practice the owner of a mark complains and the extension can be removed; according to a shared Google exchange the
developer can then only publish **a new package under a new name**
([example](https://gist.github.com/arkadiyt/4c7ac6b2fb64afd404e04af083e3f341)) — renaming after launch can mean losing
users and ratings. Beware of fake "copyright complaint" phishing e-mails; verify complaints only in the Developer
Dashboard.

**Domain disputes:** a mark owner who proves a domain is similar to their mark **and** registered in bad faith can take
it via UDRP. Running a real project in good faith is the best defense; a domain containing someone's registered mark
is still risky.

**Does being free / non-commercial change anything?** A little, but don't rely on it. A public service (even free,
even with future donations) is often treated as commercial activity. Store and domain complaints barely care about
income. Advantage: no bad faith and no money involved → low damages risk; disputes usually end with "rename".

**The name's own weakness:** "Screen With Me" is descriptive and the category has many look-alikes; descriptive names
risk refusal at registration and are hard to defend. Invented or unexpected names (Kodak, Spotify) are the strongest.

## 4. Trademark registration in Turkey
1. Preliminary search (section 2).
2. Application via EPATS with e-Devlet (turkpatent.gov.tr): form, sample (word mark; logo separately or combined),
   classes and goods/services list, fee payment.
3. Formal examination (time given to complete missing items).
4. Substantive examination (distinctiveness, descriptiveness, identical/very similar earlier marks).
5. Publication in the Official Trademark Bulletin, **2-month opposition period**.
6. Registration fee → certificate. Protection **10 years**, renewable every 10 years.

**Duration:** about **6–12 months** for a complete application without opposition. Protection starts on the filing
date (priority from the day you file).

**2026 official fees (excluding attorney fee and VAT; verify against TÜRKPATENT's current tariff):**

| Item | Fee |
|---|---|
| Application, 1st class | 2,820 TL |
| 2nd class | +2,820 TL |
| 3rd and each further class | +3,150 TL |
| Registration fee (independent of classes) | 7,010 TL |
| **Total: 1 class / 2 classes (9+42) / 3 / 4** | **9,830 / 12,650 / 15,800 / 18,950 TL** |

Sources: [Asil Patent](https://asil.com.tr/ucret/2026/marka-tescil), [Webx](https://www.webx.net.tr/tr/blog/marka-tescil-ucretleri-2026),
[Adapte Dijital](https://adaptedijital.com/dijital-marka-kur/marka-tescil-ucretleri-son-durum/). An attorney usually
adds a few thousand TL.

**Can I do it alone?** Yes: a natural person resident in Turkey doesn't need an attorney (e-Devlet). An attorney
helps with the goods/services wording (too narrow = weak protection, too broad = oppositions), similarity assessment
and replying to oppositions. ⚖️ If an opposition comes, definitely use an attorney.

**EU, US and Madrid:**
- **EU (EUIPO):** one application for 27 countries; online 1 class **850 €**, 2nd **+50 €**, 3rd and more **+150 €**
  each. Applicants from outside the EEA must use an EU representative for later steps (verify).
- **US (USPTO):** **350 $** base fee per class (since 2025); applicants living outside the US **must appoint a US
  attorney**. ⚖️
- **Madrid Protocol (WIPO):** Turkey is a member; the TÜRKPATENT application can be the "basic" one for a single
  international filing through TÜRKPATENT. Base fee **653 CHF** + each country's fee. Dependent on the Turkish
  application for the first 5 years (if refused in Turkey, everything falls).
- **Paris priority:** filing in the EU/US within **6 months** after the Turkish filing keeps the Turkish date.

## 6. Recommendation and steps
**Recommendation:** don't decide finally without looking at the AI product the owner saw, but with current findings
**staying with ScreenWithMe is possible**: no trace of a registered identical mark, the only known use is in another
field. Still, the descriptive name and crowded category are a long-term weakness. If that product turns out to be
**registered as a software/AI screen product**, rename (one of the top 3). If renaming, do it **before the Web Store
submission and the domain purchase**; later it is expensive (new store package, ratings and invite links lost).

1. Owner: share the link of that AI product; run the 4 database searches in section 2 (30 min), share screenshots.
2. Decision (1–2 days): clean → keep ScreenWithMe; registered conflict → choose a new name.
3. Domain: buy `.app` (and `.com` if possible) for the chosen name (~10–15 $/year, Cloudflare Registrar).
4. If renaming: Claude renames everything in code and texts (site, extension, READMEs, store form, e-mail) in one PR.
5. Web Store submission (1.0).
6. Trademark filing (TÜRKPATENT, word mark, classes 9 + 42, optionally 38): ~12,650 TL for 2 classes. Owner's decision
   (money); recommended after 1.0 and the first real users, but within a few months, before someone takes the name.
   An invented name (like Sofaloop) registers more easily.
7. If needed (within 6 months): extend to EU/US via Madrid ⚖️.

**⚖️ Questions for a lawyer / trademark attorney:**
- If that AI product is **registered** in 9/38/41/42: the risk of continuing with the name.
- If a **cease-and-desist** or a store/domain complaint arrives (before replying).
- The **goods/services wording** of the application and the refusal risk of "Screen With Me" for descriptiveness.
- If an **opposition** is filed against the TÜRKPATENT application.
- **EU/US applications** (a US attorney is mandatory anyway).
- Before accepting donations: how the structure (personal project vs. sole proprietorship) affects in whose name the
  trademark is registered.
