# Research: can we use "Sidelit"? + 15 new name candidates

_Research session, 3 Nov 2026, Job 6 from the Planner. Input: `name-ideas.md` "Round 3" (council: Sidelit).
**Not legal advice.** A trademark attorney (in Turkey a registered "marka vekili" listed by TÜRKPATENT) must confirm
before anything is filed or bought._

## What could and could not be reached from this cloud session

| Check | Reached? | How |
|---|---|---|
| Trademark registries (TÜRKPATENT, EUIPO / TMview, USPTO, WIPO Global Brand Database) | **No.** `tmsearch.uspto.gov` and the others are outside the session's allowed domains; registry pages are also JavaScript apps | web search for registry mirrors (markinton.com, trademarkdir.com, uspto.report) |
| Domains (RDAP / whois / DNS) | **No.** `rdap.org`, Verisign / Google RDAP, DNS-over-HTTPS and plain DNS all blocked (proxy answers 403 / no resolver) | web search for live sites only |
| App stores, Product Hunt, social handles | **Partly**: through web search results, not the stores' own search | web search |
| Companies using the word | yes, web search | web search |

So every "clean" below means **"a web search found nothing"**, not "free". The owner's own checks are listed at the end.

### What the owner must check himself (step by step)
1. **TÜRKPATENT** (https://www.turkpatent.gov.tr/arastirma-yap): "Marka Araştırma" → write `sidelit`, then
   `sidelight`, `side lit`, `sidelite`; look at classes **9** (software, apps), **38** (streaming / telecom), **41**
   (entertainment), **42** (SaaS). Note any live record (owner, class, status). Needs an e-Devlet login.
2. **TMview** (https://www.tmdn.org/tmview): search `sidelit` (and the variants), filter by Nice classes 9, 38, 41, 42;
   it covers EUIPO and most national offices (also Turkey).
3. **USPTO** (https://tmsearch.uspto.gov): type `sidelit`; also try `CM:sidelit` (combined mark field). Open any hit's
   TSDR page: status "LIVE" + class 9/38/41/42 = a problem, other classes = usually fine.
4. **WIPO Global Brand Database** (https://branddb.wipo.int): same words; it shows international (Madrid) marks.
5. **Domains:** open https://rdap.org/domain/sidelit.com (repeat for `.app`, `.io`, `.tv`, `getsidelit.com`,
   `sidelight.com`). "404 / not found" = probably free; a JSON with "events: registration" = taken (see the date and
   registrar). Also type each address in the browser (parked page or real site?). Cloudflare Registrar shows prices.
6. **Stores and handles:** search "Sidelit" in the Chrome Web Store, Google Play, App Store and Product Hunt; open
   instagram.com/sidelit, tiktok.com/@sidelit, x.com/sidelit, youtube.com/@sidelit, github.com/sidelit (a 404 page =
   free, but the app may still block it; try to create it).
7. Write each result (date, link, screenshot) into `name-ideas.md` and give it to the Planner; then a **marka vekili**
   reads the registry results before filing.

### Top 5
1. **Samewave**: the slogan in one word ("Different screens, same wave"), not a dictionary word, nothing found; grows
   with games / TV (it is about the moment, not furniture). Risk: "-wave" is common in brand names.
2. **Samelo**: invented, short, easy in both languages, owns its search results; meaning has to be taught
   ("same" + a warm ending). Risk: SIMELO in class 11 (different goods; fine in our classes, check anyway).
3. **Parallo**: "parallel screens" in both EN and TR; caution for Parallelo / Parloa (different fields).
4. **Nowly**: short and modern; caution: one letter from Newly (an app builder) in tech.
5. **Bothnow**: clearest meaning in English, nothing found; weak for Turkish speakers.

Same rules as Sidelit apply to every one: registries, domains and handles must be checked by the owner (steps 1–7
above, with the name swapped), then a marka vekili.
